# GitHub repository settings

[Perrodevs/3ds-chess](https://github.com/Perrodevs/3ds-chess) is private, with
`main` as the default branch. The short description is “Offline pixel-art chess
for Nintendo 3DS. Native C++17 engine, dual-screen controls, AI rivals,
independent profiles and training.”

Topics in the repository are `nintendo-3ds`, `3ds-homebrew`, `homebrew`,
`chess`, `chess-engine`, `pixel-art`, `retro-gaming`, `devkitpro`,
`devkitarm`, `libctru`, `citro2d`, `cpp`, `cpp17`, `dual-screen`,
`offline-game` and `game-development`. The open-source topic can be considered
after the publication and asset review.

The presentation update adds the labels `performance`, `testing`, `ui-ux`,
`chess-engine` and `hardware`. It keeps existing labels including `bug`,
`enhancement`, `documentation`, `good first issue` and `help wanted`.

The project has no configured homepage. A [social preview](media/social-preview.png)
is ready at 1280 × 640. GitHub documents that first-time social image uploads
require a public repository. This private repository has no prior custom
image. After authorized publication, upload the image in **Settings → General
→ Social preview**. [GitHub instructions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview)

Follow the [private Git workflow](GIT_LOCAL.md). The repository currently uses
a review policy for `main` in its contributor instructions. The presentation
update does not configure a GitHub branch-protection rule. The [rights inventory](ASSET_RIGHTS.md)
and [roadmap](ROADMAP.md) track requirements for a future release.
