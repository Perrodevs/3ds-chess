# Antes de declarar estable una versión

Estas pruebas requieren una **Old Nintendo 3DS XL física**. Aún no están hechas.

- [ ] Copiar el ZIP para SD y arrancar desde Homebrew Launcher.
- [ ] Ver ambas pantallas, 64 casillas, piezas completas y fuente legible.
- [ ] Jugar con cruceta/A/B sin táctil; probar repetición al mantener cruceta.
- [ ] Probar selección táctil inferior; no tocar el tablero superior.
- [ ] Elegir los cuarenta rivales y comprobar sus retratos/expresiones y el rival guardado.
- [ ] Terminar partidas contra Bajo, Normal y Fuerte, y una partida local.
- [ ] Enroques, al paso, las cuatro promociones, jaque y mate.
- [ ] Reclamación actual y por jugada prevista, y tablas automáticas.
- [ ] Guardar, cerrar, volver a abrir y comprobar SAN y repetición.
- [ ] Cobrar una vez, comprar y equipar cada categoría; cerrar y comprobar saldo.
- [ ] Exportar PGN, abrirlo en un visor y comprobar notación internacional.
- [ ] Probar audio con DSP disponible y arranque silencioso sin DSP.
- [ ] Activar/desactivar música y efectos; escuchar selección, captura y resultado.
- [ ] Cerrar tapa durante búsqueda; despertar sin jugada atrasada ni bloqueo.
- [ ] HOME/suspensión y salida durante búsqueda; asegurar cancelación segura.
- [ ] Probar SD llena/protegida con una copia de datos de prueba; comprobar aviso.
- [ ] Medir memoria dinámica, tiempos de IA, fluidez y batería sin modo New 3DS.

No cortes alimentación deliberadamente durante escrituras de tus datos reales.
Para pruebas de interrupción usa una tarjeta/copia de pruebas prescindible.

- [ ] Práctica: deshacer con blancas/negras; revisión42jugadas y revancha sin respuesta antigua.
- [ ]8puzzles,4retos y8etapas de campaña, guardado normal intacto al salir.
- [ ] Reportar versión0.8.2RC, backend y evidencia real sin estimar batería/temperatura.
