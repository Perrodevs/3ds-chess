# Solo pruebas locales — no redistribuir

Estos paquetes conservan el juego completo para que el propietario realice sus
pruebas. Contienen retratos con permisos de redistribución pendientes; véase
ASSET_RIGHTS.md. No son una autorización para publicarlos, subirlos a GitHub,
compartirlos con terceros ni venderlos. No se publica ni envía nada al empaquetar.

Las piezas personales de Cosunosuke permanecen en private/ y nunca se incluyen en
los ZIP. El binario principal usa piezas originales, pero sigue incluyendo el
atlas completo de retratos con condiciones mixtas. Sin firmware DSP ni claves.

La versión es candidata a pruebas físicas, no una certificación de estabilidad
ni una medición de batería, audio, temperatura o suspensión en hardware real.
