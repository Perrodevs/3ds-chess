# Security

The project currently distributes no public release. Report vulnerabilities in
the code or risks to local saves privately through an established channel with
a repository maintainer. If the repository offers private vulnerability
reporting, you can also use its [security page](https://github.com/Perrodevs/3ds-chess/security).

Include the branch or commit, affected platform, expected behavior and steps
using synthetic data. Please omit credentials, save contents, full personal
logs and identifying details. Share sensitive findings privately until the
maintainer can assess the report and coordinate a fix. Report non-sensitive
regressions using the [bug form](.github/ISSUE_TEMPLATE/bug-report.yml).

También puedes enviar tu reporte en español.
